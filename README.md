# Генерация промоторных последовательностей ДНК

Проект генерирует синтетические бактериальные σ70-промоторы, оценивает их
качество k-mer-классификатором и сохраняет весь эксперимент в ClearML.
Последовательности имеют длину 81 нуклеотид (`-60…+20` относительно точки
старта транскрипции) и содержат вариативные элементы `-35` (`TTGACA`) и `-10`
(`TATAAT`) с биологически правдоподобным спейсером.

## Что реализовано

- генерация сильных, средних и слабых промоторов;
- контролируемые мутации мотивов, GC-состав и A/T-богатый UP-участок;
- генерация фоновых последовательностей без случайно возникшей полной
  промоторной архитектуры;
- воспроизводимость всех результатов по `seed`;
- экспорт в FASTA и CSV;
- k-mer TF-IDF + логистическая регрессия для независимой оценки кандидатов;
- hold-out и 5-fold cross-validation;
- нативные интерактивные Plotly-графики через `ClearML Logger.report_plotly`;
- артефакты эксперимента: датасет, кандидаты, модель и JSON с метриками;
- тесты генератора, форматов и модели.

## Быстрый старт

Требуется Python 3.9 или новее.

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements-dev.txt
python -m pip install -e .
```

Сгенерировать FASTA без запуска эксперимента:

```powershell
promoter-gen generate --count 20 --strength strong --output outputs/strong.fasta
```

Провести локальную проверку без ClearML:

```powershell
python scripts/run.py --no-clearml
```

Записать эксперимент локально в формате ClearML Offline Session:

```powershell
python scripts/run.py --offline
```

Запустить онлайн после настройки ClearML:

```powershell
clearml-init
python scripts/run.py
```

Параметры эксперимента:

```text
--n-promoters      число положительных примеров (по умолчанию 1200)
--n-background     число фоновых примеров (по умолчанию 1200)
--n-generated      число кандидатов каждой силы (по умолчанию 200)
--seed             seed всех генераторов (по умолчанию 42)
--output-dir       каталог артефактов (по умолчанию outputs)
--offline          ClearML Offline Mode
--no-clearml       не создавать ClearML Task
```

## Биологическая модель

Модель предназначена для учебного in silico эксперимента, а не для прямого
лабораторного применения. Для каждого положительного примера:

1. создаётся фоновая последовательность с заданным распределением A/C/G/T;
2. UP-участок обогащается A/T;
3. в допустимых позициях размещается элемент `-35`;
4. после спейсера длиной 15–19 нуклеотидов размещается элемент `-10`;
5. мотивы мутируют с вероятностью, зависящей от требуемой силы промотора.

Сильные промоторы ближе к консенсусу и чаще имеют оптимальный спейсер 17 нт.
Фоновые примеры проходят rejection sampling, чтобы пара близких к консенсусу
мотивов случайно не образовала полноценную архитектуру.
